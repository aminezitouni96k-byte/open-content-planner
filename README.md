# Open Content Planner

Open Content Planner is a free and open-source web tool that helps schools, small businesses, associations, and digital creators organize their social media content.

## Live Demo

https://aminezitouni96k-byte.github.io/open-content-planner/

## Features

- Create planned social media posts
- Choose a publication platform
- Select a publication date
- Add a content description
- Save posts automatically in the browser
- Filter posts by platform
- Delete individual posts
- Clear all planned posts
- Responsive design for desktop and mobile
- No account or installation required

## Supported Platforms

- Instagram
- Facebook
- LinkedIn
- TikTok
- YouTube
- Other platforms

## How to Use

1. Enter a post title.
2. Select the social media platform.
3. Choose the publication date.
4. Add a description of the content.
5. Click **Add to content plan**.
6. Use the platform filter to organize your planned posts.
7. Delete posts individually or clear the entire plan.

## Data and Privacy

The application does not send user data to an external server. Planned posts are stored locally in the user's browser using localStorage.

## Project Goal

The goal of this project is to provide a simple and accessible content planning solution for organizations and creators who cannot afford expensive content management software.

Future improvements may include calendar views, multilingual support, export options, content status tracking, and collaborative planning.
